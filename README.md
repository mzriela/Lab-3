# Lab-3
An Arduino lab where I learned how to work with binary numbers, bits, and bit manipulation using a DIP switch, LEDs and the Serial Monitor.

# Required Components
- Arduino Uno
- Breadboard
- 1 x 4-Bit DIP Switch
- 4 x 220 ohm resistors
- 4 green LEDs
- Jumper wires
- USB cable

# Software 
- Visual Studio Code
- PlatformIO
- Github
